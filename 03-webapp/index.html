Lifecycle log

Automatic refresh queries the control plane only, so it can display a suspended MicroVM without waking it. Wake via HTTPS and Run cell send real traffic, which is what resumes one.

Sizing, idle policy and lifetime are reported live in each panel's configuration table — those values are what the controller actually passed to RunMicrovm.
Suspension stops compute charges, but the snapshot write and the read on resume are billed per cycle, and every image carries a one-week storage minimum. Run destroy.sh when you are finished.
